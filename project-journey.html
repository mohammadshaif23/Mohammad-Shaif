Project Journey

This page summarizes the prompts used to build and improve the Mohammad-Shaif-Snake game, along with short results for each step.

  1. Prompt: Create a snake game with apples (+points), rocks (-points), game over at 12 points, and make it accessible/shareable.
    Result: Built core HTML/CSS/JS game, scoring rules, 12-point win condition, ARIA support, and deployment instructions.
  2. Prompt: Use up/down style controls and build the website.
    Result: Added clearer control support and completed a runnable browser website structure.
  3. Prompt: Name the website "Mohammad-Shaif-Snake game".
    Result: Updated project title and heading to the requested name.
  4. Prompt: Need a website URL to test the game.
    Result: Guided publishing via GitHub Pages and shared expected live URL format.
  5. Prompt: Can't find build/deployment settings and domain errors.
    Result: Provided GitHub Pages settings path, valid domain formatting guidance, and troubleshooting steps.
  6. Prompt: Confirm repo root/settings and fix URL path issues.
    Result: Shared repo root path and corrected URL structure examples.
  7. Prompt: Arrow keys move webpage while playing.
    Result: Updated keyboard logic with preventDefault() so arrows control snake without scrolling page.
  8. Prompt: Add the live website URL in GitHub/project docs.
    Result: Added live URL section to README for quick access and sharing.
  9. Prompt: Request new PRs due branch update issues.
    Result: Created follow-up commits/PRs and added README troubleshooting for non-updating Pages deployments.
  10. Prompt: Collect all prompts and summarize results in a webpage.
    Result: Added this Project Journey page to be part of the website.
